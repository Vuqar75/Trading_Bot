## Совместимость истории и версия

Новые context имеют candidate_policy=entry-stop-nearest-v1, включённый в snapshot_id. Отсутствие поля означает прежнее distance-rr-v1; context получает явный legacy-режим при проверке старого source. Для четырёх последних старых срезов сохранённый hash и context восстановились точно. Более ранняя cap3-версия остаётся архивной исходной версией для её исторического воспроизведения; старые записи не мигрируются. Ledger VERSION/капитал/счета не пересоздавались. Модель по-прежнему может выбрать WAIT; формат ответа, её рисковые ограничения и платное расписание не менялись.
