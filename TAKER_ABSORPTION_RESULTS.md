# Поток сделок без движения цены: результат фиксированного теста

**Конфигурация отклонена для paper-наблюдения.** Все три актива убыточны
после заданных расходов в базе и стрессе. ETH и SOL дополнительно не достигли
минимума 30 закрытых сделок. Прибыльная стратегия этим этапом не получена.

## Гипотеза и отсутствие подгонки

Протокол, исходный код, шесть целевых тестов и хеши зависимостей опубликованы
**до расчёта** в `0363eda`, ветка `research/published-ema-replication`.
См. `TAKER_ABSORPTION_PROTOCOL.md` и `TAKER_ABSORPTION_INPUTS.json`.
Исследован один вариант на трёх прежних активах, без перебора порогов.

На 15m-свече: объём >=1,5 среднего предыдущих 96 свечей, дисбаланс taker
volume по модулю >=20%, тело <=0,25 предшествующего ATR14. Следующая
закрытая свеча должна подтвердить движение против агрессивного потока
пробоем opposite high/low первой свечи. Лишь после этого возможен вход.
Уровни ATR, комиссии, delayed fill, funding, stop/target и time-exit взяты
из неизменного прежнего `outcome()`. Никакой ML не обучался и не вызывался.

Это новый косвенный price/trade-volume признак. Он **не** устанавливает
поглощение конкретными лимитными заявками или order-book OFI. Прочитанный
первоисточник [Cont, Kukanov, Stoikov](https://arxiv.org/abs/1011.6402)
различает эти величины и отмечает меньшую устойчивость trade-volume связи;
доходность статьи на другой информации не переносится на этот тест.

## Данные и результат

2025-01 — 2026-10, прогрев с 2024-12. 210 уже закреплённых источников
trade/mark/funding для BTC, ETH, SOL. `volume` и `taker_buy_volume` прочитаны
из тех же исходных архивов, header, границы 0<=buy<=volume, хеши и полнота
проверены; отсутствующие данные нулём не заменялись. Новых рыночных запросов
или архивов не было. Эта история уже использовалась проектом и не является
независимым подтверждением будущей доходности.

Каждая строка — отдельный виртуальный счёт 1000 USDT. Notional<=100 USDT,
1x и расчётный риск<=5 USDT; сценарные lot/minimum proxies, не подтверждённые
исторические биржевые фильтры. Это offline-исполнения модели, не ордера VM.

Подготовительных setup-свечей было 180 BTC, 101 ETH, 108 SOL; всего 389.
Входное подтверждение получили 96. Для BTC в каждом сценарии 12 входов

Предел не увеличивался. Направления закрытых LONG/SHORT: BTC 13/22,

Gross − комиссии − impact + funding = net; модельной ликвидации нет.
В каждом из четырёх календарных сегментов сумма трёх stress-счетов
отрицательна. Сумма без лучшей сделки также отрицательна. Консервативная
MTM-просадка каждого счёта <2% (максимум 1,128%), но прохождение только
рискового критерия не компенсирует отрицательную экономику. Проверенный
финансовый результат не превращает ранее отклонённую модель в прибыльную.

Положительный gross SOL — не повод выбирать SOL или отменять стресс:
после расходов оба результата отрицательны, закрытых случаев только 23.
Именно этот вариант не переносится в торговый сервис. Maker, другой
hold/ATR/порог и новые активы по этим результатам не выбирались.

## Проверки и границы вывода

Шесть целевых тестов прошли: строгая причинность setup/следующего close,
касание без закрытия не подтверждает вход, будущие цены/объёмы не меняют
сформированный сигнал, missing/invalid buy-volume отклоняется, дополнительный
100-USDT guard не наследует больший BTC cap helper-а, cash/PnL сходятся.
На фактических массивах прошёл prefix-тест для каждого актива.

Независимый `tools/audit_taker_absorption.py` проверяет все **389 setup**
и **166 закрытых записей** двух сценариев: опубликованные исходные хеши,
идентичность источников, полный набор подтверждённых сигналов, времена,
отсутствие перекрытий внутри счёта, fill-цены, комиссии, funding, капитал,
размер/расчётный риск, периоды и решение по критериям. Аудит не выполняет
обучение, backtest или HTTP. Минутная MTM-граница считается runner-ом;
аудитор не восстанавливает её независимо из повторно загруженных mark-рядов.

Исторические bid/ask, очередь, partial fills и точная исполнимость стопа
не установлены. При неоднозначности прежний outcome не зачисляет спорный
положительный funding; отрицательный может быть консервативно учтён.
Изменение задержки/impact меняет путь, поэтому разница base/stress не является
чистым причинным эффектом одного размера комиссии.

Результаты и журналы: `research/taker_absorption_results/` (менее 150 KB).
Воспроизведение без новых источников:

```bash
python -m research.taker_absorption /workspace/work/rsi-crossasset-data research/taker_absorption_results
python tools/audit_taker_absorption.py
```
