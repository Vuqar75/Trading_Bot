# Проверка часового разворота вместо TIME
Закреплено до расчёта. BTCUSDT USD-M. Сравнение 1 января — 31 октября 2026 UTC, отдельные отчётные блоки январь–март, апрель–июнь, июль–октябрь. История уже использовалась проектом. Ноябрьское снижение только диагностическое. Параметры заморожены.

Путь входа и SL/TP из ACTION_VALUE_PROTOCOL и e644843, те же ATR уровни, BTC sizing, cash 1000, одна позиция, 1x, cap 100 USDT, риск 5 USDT с прежним резервом издержек. Та же минутная прокси, задержки +1/+6 минут, комиссии 5 б.п. на сторону, spread/impact 5/10 на сторону, реальный funding по минутному mark. Защита по сделкам, стоп по худшему открытому уровню гэпа, TP без улучшения, при двух касаниях внутри минуты стоп первым.

После входа SHORT завершённый час должен закрыться строго выше максимума high четырёх предшествующих часовых свечей. Для LONG строго ниже минимума low. Нужны пять полных часов. Сигналы на границе до исполнения входа не применяются. Выход на следующем минутном open через +1/+6 минут от границы. SL/TP действуют в ожидании. Если на open запланированного выхода уже пробит защитный барьер, учесть защитный выход по этому open для стопа либо по цели, без улучшения для TP. Для сравнения старый TIME остаётся точно как в e644843, по open в дедлайн. Аварийный срок 48ч, который имеет приоритет перед более поздним разворотом. Дебет при неразрешимом порядке funding и защиты внутри минуты, неизвестный участок без вымышленных fills.

Парное сравнение каждого 15m LONG и SHORT, включая WAIT модели, без конфликтов капитала между независимыми строками. Фильтры и оценочный риск проверяются при 1000 USDT. Для полного сравнения ограничиваем обе политики входами с полным 48h горизонтом до конца архива. В последовательном сравнении обе политики используют только знак предыдущей закрытой часовой свечи из e644843. Одинаковые возможности, отдельный непрерывный счёт, сигналы при занятой позиции пропускаются. Декомпозиция по общим и уникальным id timestamp+сторона. Просадка по консервативным экстремумам mark, cash и затратам на выход. До допуска требуется минимум 100 закрытий в каждом сценарии, минимум 30 каждого направления, max MTM DD <=2% в каждом, стрессовый net >0 и выше 4h выхода, стрессовый net без лучшей >0. База также должна быть положительной. Выход сам по себе недостаточен для допуска.

Ноябрь: все 130 сохранённых решений проверяются независимо на SHORT с прежним 4h выходом. Для TIME проследить оставшееся движение через первоначальные уровни до 48h от входа либо до конца доступных минут, с флагом усечения и неоднозначности. Отдельный счёт принудительного SHORT по тем же возможностям показывает эффект взаимного исключения входов и является диагностикой. Штатный GPT сопоставляется по ранее сохранённым квитанциям. Внешних вызовов модели нет. Месячные журналы пишутся атомарно и используются при возобновлении.
