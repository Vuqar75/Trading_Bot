# Один тест: поток сделок без движения цены и последующее подтверждение

Протокол фиксируется до расчёта, 12 ноября 2026. Только offline, без новой
модели, перебора, коллектора, платного API и изменений рабочей VM.

Гипотеза: высокий объём агрессивных покупок без соответствующего роста
может означать встречное предложение. Если СЛЕДУЮЩАЯ закрытая свеча пробивает
минимум такой свечи, проверить SHORT; симметрично для агрессивных продаж
и LONG. Это косвенный price/trade-volume признак, не доказательство
поглощения лимитными заявками, очереди или будущего преимущества.

Первоисточник для различения: Cont, Kukanov, Stoikov, The Price Impact of
Order Book Events, https://arxiv.org/abs/1011.6402 . Abstract прочитан сегодня:
их OFI включает limit orders и cancellations на best bid/ask; trade volume
менее устойчив. Данный тест НЕ воспроизводит их order-book signal и доходность
из этой статьи не заимствуется. Поля архива проверены по фактическому header
USD-M: volume и taker_buy_volume; I=(2*buy-volume)/volume, не L2 OFI.

Источники: только закреплённые минутные BTC/ETH/SOL USD-M trade/mark/funding
архивы, 2024-12 для прогрева, 2025-01 — 2026-10 для расчёта. История уже
использовалась проектом: положительный результат не независимое подтверждение.
Не выбирать актив/сторону или менять условия после результатов.

Условия на закрытой 15m setup-свече i:

1. Базовый объём >=1.5 среднего объёма ПРЕДЫДУЩИХ 96 свечей, без текущей.
2. |I|>=0.20; volume>0, 0<=buy<=volume; отсутствующее buy не заменять нулём.
3. |close-open| <=0.25 ATR14, где ATR14 — Wilder TR по закрытым свечам
   строго ДО setup-свечи. Это малый net-body, не малый внутрисвечной range.
4. Для I>=0.20 только SHORT и только если следующая 15m свеча закрылась
   ниже low setup; для I<=-0.20 только LONG и только если следующая
   закрылась выше high setup. Подтверждение действительно ровно одну свечу;
   его high/low в одиночку недостаточно. Решение доступно лишь ПОСЛЕ её close.

Исполнение — существующий неизменный outcome() из pattern_ai_experiment.py:
вход T+1min base / T+6min stress; taker fee5bps/side, impact5/10bps/side;
stop=clip(1.5*ATRprior/close_setup,0.5%,2%), target2R; максимум4h от входа,
пессимистичный stop/target tie, гэпы, mark и funding. Повторно не обучать ML.
ATR берётся из setup, без будущей confirmation-свечи. Сохранить весь outcome.

Отдельные виртуальные счета1000 USDT на актив/сценарий. Не более одной
позиции на каждом, ignore signals до фактического exit. Прежний sizing-helper
только предлагает qty; ДО допуска дополнительно проверять <=100 USDT по
max(fill,mark), 1x, расчётный риск<=5 USDT, хватает cash+fee. BTC0.001,
ETH0.001,SOL0.01 и прежние min-notional — СЦЕНАРНЫЙ текущий proxy, а не
доказанные исторические filters. BTC>100 USDT не обходить увеличением лимита.
Сохранить все отказанные и занятые сигналы, funding и ledger. Конечное
неполное окно отклонить. MTM-просадка — консервативная минутная mark-граница
с расходами выхода; стоп не гарантирует исполнимую цену.

Критерии продолжения заданы заранее: в каждом активе/сценарии >=30 закрытых,
>=10 в каждом направлении; base и stress net>0 ДЛЯ КАЖДОГО актива;
совокупный stress>0 в >=3 из4 сегментов2025H1/H2,2026H1/H2;
совокупный stress>0 без лучшей сделки; каждый MTM DD<=2%.
Недостаточно наблюдений — отдельно от отрицательной экономики. Ни один
результат автоматически не разрешает установку или сделки. При отказе
не подбирать новый порог/ATR/hold/актив на этой же истории.

Проверки: prefix causality, setup и confirmation timestamps, volume bounds,
future close/high-only rejection; независимая сверка всех итоговых исполнений
через цены fill, комиссии, funding, капитал и ограничения. Только адресные
тесты нового кода; полный набор бота и завершённые эксперименты не повторять.
