# Достижимость пассивных лимитов после фильтра 1H/4H

Проверить все 44 допустимых плана из `dc10e1b` на 13 реконструированных срезах. Реконструкция сохраняет исходные свечи, котировку и генератор. Каждый план рассматривается самостоятельно. ИИ не выбирает сделку. Условная активация через 60 секунд после снимка, дедлайн строго на следующей четверти часа. На активации требуется котировка bid/ask с биржевым возрастом до 5 секунд. LONG должен оставаться ниже ask, SHORT выше bid. Если цена уже пересечена, фиксируем отклонение. Повторно лимит не двигаем.

Для проверки рыночных условий берём публичные агрегированные сделки Binance BTCUSDT USD-M. Только агрессивные продажи строго ниже лимита для LONG и агрессивные покупки строго выше для SHORT. Количество округляется вниз на шаг 0,001 BTC отдельно для каждого события. Суммируем до модельного полного размера. Проверяем последовательность ID с обеих сторон окна. Цена, прошедшая лимит в архиве, подтверждает рыночное условие. Фактическое получение свежей сделки рабочим процессом, состояние стакана при гипотетической постановке, TP/SL, PnL и выбор одного плана не подтверждаются. Платные запросы, VM и изменения политики вне проверки.
