# RSI(2) с динамическим выходом: выбор 2025 → фиксация → проверка 2026

Автор разрешил продолжать поиск без остановки после каждого отказа. Этот
пакет — следующий шаг того же поручения; рабочая VM и платный API не нужны.
Никакое число попыток не превращает случайный положительный backtest в alpha.

Мотивация и источники, прочитанные до расчёта:
- Larry Connors, Dynamic Exits, TradingMarkets, 2009-08-12:
  https://tradingmarkets.com/recent/dynamic_exits_how_to_properly_exit_a_trade-641067
  Автор рассматривает динамические выходы по RSI/короткой средней на акциях/ETF.
- StockCharts ChartSchool RSI(2):
  https://chartschool.stockcharts.com/table-of-contents/trading-strategies-and-models/trading-strategies/rsi-2
  Условия5/95, SMA200 для направления и SMA5 для выхода; источник прямо
  предупреждает, что это отправная точка, а не готовый гарантированный метод.

Это независимая intraday USD-M адаптация, не воспроизведение stock/ETF прибыли.
Вместо общего2R/ATRstop/4h outcome используется собственный выход правила.
Исходный автор не рекомендует стоп, но здесь сохраняется автоматический2%
stop и maxhold: ограничения владельца/исполнимого риска важнее чужого backtest.

Ровно3TF:15m,1h,4h; RSI2 Wilder, SMA200 и SMA5 по закрытым свечам.
LONG только close>SMA200 и новое пересечение RSI2 ниже5 (предыдущее>=5);
SHORT только close<SMA200 и новое пересечение выше95 (предыдущее<=95).
Цена и обе средние включают уже закрытый signal bar, ни одного будущего.
После входа LONG выходит при закрытии>SMA5, SHORT при закрытии<SMA5.
Без2Rtarget, усреднения, pyramiding и немедленного разворота. При открытой
позиции противоположный entry игнорируется; её сопровождение сохраняется.

Максимум удержания от фактического входа:6h/12h/24h соответственно TF.
Предзаданный time-exit на minute-open deadline, раньше неизвестного intrabar
пути; обычный mean-exit по закрытию с задержкой1/6min. Stop2% внутриминутный,
с гэпом/ликвидацией/funding через неизменный проверенный Account из
published_ema_transfer.py, извлечённый тем же AST-loader без XGBoost/importfit.
Base entry/mean-exit delay1min и impact5bp/side; stress6min/10bp. Fee5bp/side.
Максимальный hold заранее исключает поздние входы с неполным конечным окном.

Отдельные1000USDT счета,1x,расчётныйриск<=5. BTC0.001<=150USDT — тот же уже
разрешённый research cap из RSI crossasset; ETH/SOL<=100USDT с прежними
lot/minimum proxies. Это НЕ повышение лимита действующего бота. Не обходить
недостаток данных или капитал. Все отказы/ожидания/исполнения сохраняются.

Данные прежние210pinnedinputs, Dec2024warmup, Jan2025-Oct2026; 4hSMA200
становится доступной после200баров, без заполнения отсутствующего прогрева.
Вся история ранее использовалась проектом: 2026 здесь последующая проверка
нового выбора, а не нетронутый holdout и не доказанное рыночное преимущество.

Этап DEVELOPMENT: только2025,3TF×3актива×2исполнения,18счетов. Не менять
пороги. Для каждого TF/актива допустимы>=30закрытых и10каждого направления
в каждом сценарии, base/stressnet>0, обе2025половиныstress>0,
stressбезлучшей>0, DD<=2%. Из прошедших выбрать ОДИН по наибольшему stressnet,
затем большему числу stressзакрытий, затем lexicalasset/TF. Все18 раскрыть.
Winner и полный журнал2025 публикуются ДО расчёта результатов2026.

Этап VALIDATION: только выбранные TF/актив, отдельные1000USDT счета
Jan-Oct2026, без подстройки по2026 и без проверки runner-up после неудачи.
Те же count/direction/base+stresspositive/besttrade/DD критерии; обе
2026половиныstress>0. Успех — исторический кандидат только для дальнейшей
проверки исполнения/просpective paper, НЕ разрешение торговли. Данные
переиспользованы и выбор из9учтён как selection risk. При неудаче пакет
отклоняется, а не переименовывается и не чинится порогом на том же2026.

Проверки: causalprefix, flatRSI50, настоящиеSMA5выходы, time-exitpreemption,
сохранение2%stop/funding/шага/риска, задержкивхода ивыхода, no duplicate fills,
конечнаяflatstate, независимый fill/cash/fee/funding/временной аудит.
Не повторять старые обучения, полный набор приложения или VM-rollout.
