# Правила работы с Trading_Bot

Перед началом работы прочитайте HANDOFF.md: это сохранённый контекст проекта.
Следуйте ограничениям и решениям из него; обновляйте его по завершении каждого этапа.

По указанию пользователя код и HANDOFF.md каждого завершённого этапа должны быть
закоммичены в отдельную исследовательскую ветку и отправлены в GitHub. Сообщайте
пользователю название ветки и хеш коммита. Не используйте force push без разрешения.

Не обновляйте, не перезапускайте и не останавливайте работающего бота без отдельного
указания. Не читайте личную Telegram-конфигурацию и не сохраняйте секреты/Telegram ID.
Для исследований используйте отдельный checkout и временные/in-memory базы.
Новые стратегии остаются offline, пока пользователь отдельно не разрешит включение.
